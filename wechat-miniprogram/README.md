# 双休雷达 · 微信小程序

名单写在 `data/brands.js`。查询、筛选、同类推荐都在手机完成，不调用服务器，也不采集姓名 / 手机 / 微信号。

## 让别人扫码进来

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，导入本文件夹。
2. **先给自己和少数朋友用：** 点「预览」，生成二维码。他们微信扫码即可。体验版有人数和有效期限制，二维码不要公开发到网上。
3. **要长期公开扫码：** 用你的小程序账号上传并提交审核。通过后，在公众平台生成「小程序码」，任何人扫码都能进。右上角「转发」也可以发给微信好友。

## 关于「被找到」

正式上线的小程序，微信会实名登记账号主体。用户在小程序「关于」里通常能看到主体名称。腾讯能对应到你的身份证或营业执照。这是微信的规则，程序本身做不到对微信匿名。

程序里能做的：不收集使用者身份、不留主办人联系方式、新登记只存在本人手机、话术是众包备忘而不是抵制名单。

若只想给熟人用，不要提交审核，只用预览码私下发。

请勿在登记说明里填写姓名、工号、电话或内部资料。
