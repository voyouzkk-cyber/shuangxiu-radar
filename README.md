# 双休雷达

查日常品牌有没有被登记为「双休」。拍包装上的商标，或直接搜品牌名；再决定买不买。

本仓库是网页版（React）源代码，并带一份可离线用的微信小程序草稿（`wechat-miniprogram/`）。

## 这是什么

- **网页**：查品牌、看同类、登记与投票（写入公共库后，后来打开网页的人都能看到）
- **微信小程序草稿**：名单写在本地 `data/brands.js`，查询/筛选在手机完成，不调用服务器

## 原则

- 不收集姓名、手机号、微信号、位置，不设账号
- 不对任何公司作指控，也不号召抵制
- 同一公司不同岗位、时期、地区可能不同，条目可能不准
- 请勿在说明里填写姓名、工号、电话或内部资料

## 本地跑网页（开发）

需要 Node.js。在仓库根目录：

```bash
npm install
npm run dev
```

开发服务默认在 `0.0.0.0:8080`。具体以项目脚本为准。

## 微信小程序草稿

见 [`wechat-miniprogram/README.md`](./wechat-miniprogram/README.md)。导入微信开发者工具即可预览；正式对外需小程序账号审核。
